# 한국외국어대학교 부(Boo) 원본

공식 안내: https://www.hufs.ac.kr/hufs/11137/subview.do

배포 파일: https://www.hufs.ac.kr/sites/hufs/files/boo_png.zip

`boo.riv`는 공식 벡터 원본을 부품으로 분리해 제작한 서비스용 Rive 애니메이션이다. 편집 소스와 동작 계약은 `design/boo-rive/README.md`에 기록했다.

- learning.png: 원본 03.png
- encouraging.png: 원본 09.png
- celebrating.png: 원본 16.png

원본 PNG를 가공하지 않고 복사했다. 색상과 비율은 유지하며 UI 컨테이너에 등장·이동 효과를 적용한다. 캐릭터 권리는 한국외국어대학교에 있다. 공식 페이지의 사용규정은 수익 목적 상품 제작을 제한하고, 홍보용 상품 제작 및 변형 관련 협의를 안내한다. 공모전 제출·외부 공개 형태에 대한 확인은 별도 필요하며 이 파일이 이용허락을 대신하지 않는다.
