# 글꼴 출처

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Noto Sans KR: https://github.com/google/fonts/tree/main/ofl/notosanskr
- Noto Serif: https://github.com/google/fonts/tree/main/ofl/notoserif
- 글꼴은 SIL Open Font License 1.1에 따라 자체 호스팅한다. 원본 라이선스 파일을 함께 보관한다.
- 2026-11-04 원본 가변 TTF를 내려받아 fonttools로 WOFF2 변환 및 문자 범위 축소를 수행했다.
- DM Sans는 U+0000-024F, U+2000-206F를 포함한다.
- Noto Sans KR은 U+1100-11FF, U+2000-206F, U+3000-303F, U+3130-318F, U+AC00-D7AF, U+FF00-FFEF를 포함한다.
- 본문은 DM Sans를 먼저 사용하고 한글은 Noto Sans KR로 표시한다. 포함하지 않은 문자는 시스템 sans-serif로 보완한다.
- Noto Serif Regular는 2026-11-09 Google Fonts에서 받은 TTF를 자체 호스팅하며 공개 화면의 영문 원문 예시에 사용한다. SIL Open Font License 1.1 원본을 함께 보관한다.
