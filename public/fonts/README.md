# 글꼴 출처

- Noto Sans KR: https://github.com/google/fonts/tree/main/ofl/notosanskr
- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Source Serif 4: https://github.com/google/fonts/tree/main/ofl/sourceserif4
- 글꼴은 SIL Open Font License 1.1에 따라 자체 호스팅한다. 원본 라이선스 파일을 함께 보관한다.
- 2026-11-16 Google Fonts 저장소의 가변 TTF를 내려받아 fonttools로 WOFF2 변환과 문자 범위 축소를 수행했다.
- Noto Sans KR은 본문 글꼴이며 U+0000-024F, U+1100-11FF, U+2000-206F, U+2190-21FF, U+3000-303F, U+3130-318F, U+AC00-D7AF, U+FF00-FFEF를 포함한다.
- Space Grotesk는 숫자와 영문 강조용이며 U+0000-024F, U+2000-206F를 포함한다.
- Source Serif 4는 원문 인용과 PDF 원문 예시용이며 U+0000-024F, U+2000-206F를 포함한다.
- 포함하지 않은 문자는 시스템 글꼴로 보완한다.
