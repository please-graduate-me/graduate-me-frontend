# 디자인 결정

리디자인(2026-11)에서 정한 디자인 방향과 화면 규칙이다. 토큰 값은 `lib/styles/theme.css.ts`, 컴포넌트 규칙은 [Architecture.md](../Architecture.md)를 따른다. 업무 규칙(리그, 복습 간격 등)은 백엔드 저장소 `docs/business-rules.md`에 있다.

## 시안

- 기준 시안은 Claude Design 캔버스 https://claude.ai/artifact/BYs7pM4yXvyqDEorrgzAxb 이다. `project/canvas.json`과 `project/<화면>.dc.html`로 구성된다.
- 시안 HTML의 `renderVals()` 값은 예시 데이터라 화면에 그대로 넣지 않는다.
- 현재 화면은 시안을 반영한 상태다. 이후 수정은 현재 코드를 기준으로 하고, 시안은 아래 "시안과 다르게 정한 것"을 확인하거나 미정 항목을 정할 때 참고한다.
- 화면 구조와 움직임은 Brilliant 웹을 참고했지만 색, 일러스트, 문구는 자체 것을 쓴다. 타사 디자인을 복제하지 않는다.

## 브랜드

- 서비스 표기는 "Please graduate me", 약칭 PGM이다.
- 로고 B안(검정 둥근 사각형 안 학사모 쓴 P)은 헤더, 앱 아이콘, 파비콘에 쓴다.
- 로고 D안(PLEASE · GRADUATE · ME 원형 졸업 도장)은 레슨 정답, 완료 축하, 랜딩 장식에만 쓴다.
- 마스코트 Boo는 한국외국어대학교 캐릭터다. 변형하거나 로고와 합치지 않는다.

## 색과 글꼴

- 잉크(#16181D): 본문 글자, 먹색 강조 카드와 주요 버튼
- 청록(#0B7A62, 밝은 #12A47F): 정답, 진행, 저장 같은 긍정 동작
- 주황(#C2540A, 밝은 #F97316): XP, 연속 기록, 강조 알림
- 글꼴은 Noto Sans KR(본문), Space Grotesk(숫자), Source Serif 4(문서)이다.

## 시안과 다르게 정한 것

- 레슨(/learn/[id]): 영상 받아쓰기 구조를 유지한다. 시안의 집중 퀴즈형 단일 열과 보기 칩은 쓰지 않고, 시안 요소를 실제 구조에 맞게 옮긴다.
- 랜딩(/): 체험은 별도 화면이 아니라 페이지 안 `#try-learning` 데모로 두고, 체험 버튼은 모두 그 위치로 스크롤한다.
- 나의 질문(/questions): 새 질문을 만들지 않는 이전 질문 보관함이다. 행동 유도 버튼은 커뮤니티 글쓰기로 연결한다.
- PDF 읽기: 번역은 저장된 설명이 있으면 바로 보여 주고, 없으면 버튼을 눌렀을 때만 생성한다. 선택할 때마다 자동으로 AI를 호출하지 않는다.
- 작성 시각: 1시간 미만은 N분 전, 24시간 미만은 N시간 전, 그다음은 어제, 그 이전은 절대 날짜로 쓴다(`lib/date/formatRelativeTime.ts`).
- 설정의 저장 상태 점은 저장 중에만 움직이고 저장이 끝나면 멈춘다.

## 아직 정하지 않은 것

- 설정의 역할 표지 문구: "학생 + 조교 공간", "학생 + 운영 공간", "학생 + 조교·운영 공간" 중 선택
- 레슨 풀이 중 번역 표시를 도움 사용으로 볼지
- 커뮤니티 목록에서 뺀 "공개 글" 배지를 되살릴지
- /admin 안내 화면을 되살릴지(지금은 /community로 이동, 시안은 `Admin.dc.html`)
